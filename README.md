# Coze 电商智能客服 Bot\n\n> 基于 Coze 平台搭建的电商领域 AI 智能客服机器人，集成知识库检索、自动建议、多轮对话能力。\n\n## ✨ 功能特性\n\n- 🤖 **专业客服人设** — 电商场景专属 Prompt，语气友好专业\n- 📚 **知识库问答** — 内置 3 份电商知识文档（FAQ / 退换货政策 / 物流配送）\n- 💡 **自动建议 (Auto-suggestion)** — 智能推荐用户可能想问的问题\n- 🎯 **开场白引导** — 预设欢迎语，提升用户体验\n- 🔗 **多渠道发布** — 支持 Agent Store、网页、API 等多端接入\n\n## 🏗️ 项目结构\n\n`\ncoze-ecommerce-bot/\n├── knowledge/                  # 知识库文档（上传到 Coze 使用）\n│   ├── 产品常见问题FAQ.md      # 16 条高频 Q&A\n│   ├── 退换货政策.md           # 退换货流程与规则\n│   └── 物流配送政策.md         # 配送时效与运费说明\n├── .gitignore\n└── README.md\n`\n\n## 🚀 快速上手\n\n### 1. 导入 Bot\n\n1. 访问 [Coze 官网](https://www.coze.cn/) 并登录\n2. 进入 **Agent Store** 或使用 Bot 链接导入\n3. Fork 此仓库作为知识库备份\n\n### 2. 配置知识库\n\n在 Coze 平台操作：\n\n1. 打开 Bot → 左侧 **Knowledge** 模块\n2. 点击 **Create knowledge base**\n3. 上传 knowledge/ 目录下的 3 个 .md 文件\n4. 等待分片和索引完成（约 1-2 分钟）\n5. 在 **Workflow** 中关联知识库节点\n\n### 3. 测试验证\n\n在 Preview 中测试以下问题：\n\n| 测试问题 | 预期回答来源 |\n|----------|-------------|\n| 退货流程是什么？ | 退换货政策.md |\n| 发货要几天？ | 物流配送政策.md |\n| 支持哪些支付方式？ | 产品常见问题FAQ.md |\n| 怎么联系客服？ | 产品常见问题FAQ.md |\n\n## 🛠️ 技术栈\n\n| 组件 | 技术 |\n|------|------|\n| 平台 | [Coze](https://www.coze.cn/) |\n| 大模型 | 通义千问 (Qwen) |\n| 知识库 | Coze Knowledge Base + Markdown 文档 |\n| 能力 | Auto-suggestion, Opening Questions, Workflow |\n\n## 📖 知识库内容概览\n\n### 产品常见问题 FAQ（16 条）\n- 账户注册与登录、订单查询与跟踪\n- 支付方式、优惠券使用、会员等级\n- 商品咨询、库存查询、尺码指南\n\n### 退换货政策\n- 7 天无理由退货条件\n- 退货流程（5 步）\n- 退款时效与方式\n- 特殊商品处理规则\n\n### 物流配送政策\n- 配送范围与时效\n- 运费标准（满额免运费）\n- 物流跟踪方法\n- 异常处理（丢件/破损）\n\n## 💡 扩展方向\n\n- [ ] 接入微信公众号 / 飞书 / 钉钉等发布渠道\n- [ ] 开启对话记忆（Memory），支持多轮上下文\n- [ ] 接入外部 API（查订单、查物流实时状态）\n- [ ] 增加更多知识库文档（商品详情、促销活动）\n- [ ] 配置人机协作模式，复杂问题转人工客服\n\n## 📝 面试亮点\n\n> 本项目适合作为 **AI Agent 应用层** 的面试展示项目：\n\n1. **低代码平台能力** — 展示对 Coze/Dify 等平台的理解\n2. **Prompt Engineering** — 人设 Prompt 设计与调优\n3. **RAG 实践** — 知识库构建、文档分片、检索效果优化\n4. **产品思维** — 从 0 到 1 完成客服机器人上线全流程\n\n## 📄 License\n\nMIT\n\n---\n\n**Bot 发布时间**: 2026-04-26  \n**作者**: [Dream22180971](https://github.com/Dream22180971)
