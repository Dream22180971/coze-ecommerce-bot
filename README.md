# Coze 电商智能客服 Bot

> 基于 Coze 平台搭建的电商领域 AI 智能客服机器人，集成知识库检索、自动建议、多轮对话能力。

## 功能特性

- **专业客服人设** - 电商场景专属 Prompt，语气友好专业
- **知识库问答** - 内置 3 份电商知识文档（FAQ / 退换货政策 / 物流配送）
- **自动建议 (Auto-suggestion)** - 智能推荐用户可能想问的问题
- **开场白引导** - 预设欢迎语，提升用户体验
- **多渠道发布** - 支持 Agent Store、网页、API 等多端接入

## 项目结构

`
coze-ecommerce-bot/

│   └── 物流配送政策.md         # 配送时效与运费说明

`

## 快速上手

### 1. 导入 Bot

1. 访问 [Coze 官网](https://www.coze.cn/) 并登录
2. 进入 **Agent Store** 或使用 Bot 链接导入
3. Fork 此仓库作为知识库备份

### 2. 配置知识库

在 Coze 平台操作：

1. 打开 Bot -> 左侧 **Knowledge** 模块
2. 点击 **Create knowledge base**
3. 上传 knowledge/ 目录下的 3 个 .md 文件
4. 等待分片和索引完成（约 1-2 分钟）
5. 在 **Workflow** 中关联知识库节点

### 3. 测试验证

在 Preview 中测试以下问题：

| 测试问题 | 预期回答来源 |
|----------|-------------|
| 退货流程是什么？ | 退换货政策.md |
| 发货要几天？ | 物流配送政策.md |
| 支持哪些支付方式？ | 产品常见问题FAQ.md |
| 怎么联系客服？ | 产品常见问题FAQ.md |

## 知识库内容概览

### 产品常见问题 FAQ（16 条）
- 账户注册与登录、订单查询与跟踪
- 支付方式、优惠券使用、会员等级
- 商品咨询、库存查询、尺码指南

### 退换货政策
- 7 天无理由退货条件
- 退货流程（5 步）
- 退款时效与方式
- 特殊商品处理规则

### 物流配送政策
- 配送范围与时效
- 运费标准（满额免运费）
- 物流跟踪方法
- 异常处理（丢件/破损）
